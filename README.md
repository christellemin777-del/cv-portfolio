Site développé en HTML5 sémantique et CSS Flexbox (sans framework), puis déployé via GitHub Pages.

## Structure du projet

- `index.html` → Structure HTML5 sémantique
- `style.css` → Mise en page Flexbox + responsive
- `assets/` → Images et CV
